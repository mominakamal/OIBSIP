# PulseFit — Landing Page

## About
A responsive static landing page built for a fictional fitness/gym app called **PulseFit**. This project was completed as part of the Oasis Infobyte (OIBSIP) Web Development & Designing internship — Level 1, Task 1.

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)

## Features
- Sticky navigation bar with 3 links (Home, Programs, Contact)
- Hero section with headline, subheadline, and call-to-action button
- Two content sections: Programs (3 cards) and Why Choose PulseFit (3 points)
- Footer with contact info and social link placeholders
- Consistent color palette (dark navy, teal accent, white/light gray)
- Fully responsive layout using CSS Grid and Flexbox — adapts to mobile screens

## How to Run
1. Download `index.html` and `style.css` into the same folder.
2. Open `index.html` in any web browser.
