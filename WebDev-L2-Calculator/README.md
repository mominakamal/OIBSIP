# Glass Calculator

A simple and responsive browser-based calculator created for Oasis Infobyte Web Development & Designing Internship - Level 2 Task 1.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication and division
- Percentage operation
- Decimal numbers
- Clear button
- Backspace button
- Division-by-zero error handling
- Operator chaining
- Responsive design
- CSS Grid button layout
- Glassmorphism user interface
- JavaScript event listeners
- No inline onclick attributes
- No eval() function
