# To-Do Web App

## About
An interactive to-do list application that lets users add, complete, edit, and delete daily tasks, organized into Pending and Completed lists. Built as part of the Oasis Infobyte (OIBSIP) Web Development & Designing internship — Level 2, Task 3.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- Add new tasks via input field
- Tasks appear immediately in the Pending list
- "Done" toggle moves tasks to the Completed list (and back with "Undo")
- Edit button to modify task text inline
- Delete button to remove tasks permanently
- Task count indicators ("X pending" / "Y completed")
- Timestamp shown for when each task was added or completed
- Tasks persist across page refreshes using localStorage
- Friendly empty-state messages when a list has no items

## How to Run
1. Download `index.html`, `style.css`, and `script.js` into the same folder.
2. Open `index.html` in any web browser.
