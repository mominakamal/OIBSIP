# Personal Portfolio

## About
A responsive personal portfolio website showcasing my skills, projects, and contact information. Built as part of the Oasis Infobyte (OIBSIP) Web Development & Designing internship — Level 1, Task 2.

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)

## Features
- Sticky navbar with smooth scroll navigation
- Profile/hero section with name, role title, and avatar placeholder
- About Me section
- Skills section displayed as a responsive badge grid
- Projects section with 2 placeholder project cards
- Contact section with name, email, and LinkedIn/GitHub link placeholders
- Consistent branding (navy + teal color palette, matching Task 1)
- Fully responsive layout

## How to Run
1. Download `index.html` and `style.css` into the same folder.
2. Open `index.html` in any web browser.
