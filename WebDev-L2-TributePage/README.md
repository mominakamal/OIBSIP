# Tribute Page — Ada Lovelace

## About
A tribute page dedicated to Ada Lovelace, widely regarded as the world's first computer programmer. Built as part of the Oasis Infobyte (OIBSIP) Web Development & Designing internship — Level 2, Task 2.

## Tech Stack
- HTML5
- CSS3

## Features
- Page title with subject's name and tagline
- Prominent image section
- Biography section with 4 paragraphs of original written content
- Timeline of key milestones in Ada Lovelace's life
- Distinctly styled quote block
- Two background colors used across sections (dark navy + light gray/white)
- Two font styles (Playfair Display for headings, Inter for body text)
- Fully responsive layout

## How to Run
1. Download `index.html` and `style.css` into the same folder.
2. Open `index.html` in any web browser.
